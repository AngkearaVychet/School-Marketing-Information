# ប្រព័ន្ធគ្រប់គ្រង និងកត់ត្រាព័ត៌មានអ្នកសួរព័ត៌មានសាលា
### School Inquiry & Admissions Management System (CRM)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងយ៉ាងពិសេសសម្រាប់សាលារៀន ក្នុងការកត់ត្រា គ្រប់គ្រង តាមដាន និងវិភាគទិន្នន័យអាណាព្យាបាល និងសិស្សដែលបានទាក់ទងមកសួរព័ត៌មានតាមរយៈគ្រប់បណ្តាញទីផ្សារ (Facebook, TikTok, Telegram, ទូរស័ព្ទ, មកផ្ទាល់ Walk-in, ការណែនាំ...)។

---

## 🚀 របៀបបើកដំណើរការកម្មវិធី (Quick Start)

អ្នកអាចបើកប្រើប្រាស់កម្មវិធីបានយ៉ាងងាយស្រួលដោយ **មិនបាច់ដំឡើង Server អ្វីទាំងអស់** (ដំណើរការ Offline បាន ១០០%)៖

1. **វិធីទី១ (ងាយស្រួលបំផុត):** ចុចពីរដង (Double click) លើឯកសារ `Start-App.bat`
2. **វិធីទី២:** ចុចពីរដងលើឯកសារ `index.html` ដើម្បីបើកក្នុង Google Chrome, Microsoft Edge ឬ Firefox

---

## ✨ មុខងារសំខាន់ៗនៃប្រព័ន្ធ (Core Features)

### ១. ផ្ទាំងគ្រប់គ្រងស្ថិតិទូទៅ (Dashboard Overview)
- បង្ហាញចំនួនអ្នកសួរព័ត៌មានសរុប (Total Inquiries)
- ចំនួនអ្នកចុះឈ្មោះរៀនជោគជ័យ (Enrolled) និងអត្រាបម្លែងជោគជ័យ (Conversion Rate %)
- ចំនួនអ្នកដែលត្រូវទាក់ទងតាមដាននៅថ្ងៃនេះ (Today's Follow-up Reminders)
- ក្រាហ្វិកវិភាគប្រភពទីផ្សារ (Marketing Channels: Facebook, TikTok, Walk-in, Telegram...)
- ក្រាហ្វិកស្ថានភាពដំណើរការរបស់ភ្ញៀវ (Pipeline Status Donut Chart)

### ២. បញ្ជីអ្នកសួរព័ត៌មាន និងតម្រងស្វែងរក (Inquiries List & Smart Filters)
- ស្វែងរកភ្លាមៗ (Real-time Live Search) តាមរយៈឈ្មោះអាណាព្យាបាល, លេខទូរស័ព្ទ, ឈ្មោះកូន, ឬលេខកូដ
- Filter តាមកម្រិតថ្នាក់ (មត្តេយ្យ, បឋម, អនុវិទ្យាល័យ, ភាសាអង់គ្លេស...)
- Filter តាមប្រភពទីផ្សារ និងចន្លោះកាលបរិច្ឆេទ (ថ្ងៃនេះ, ខែនេះ)
- ប៊ូតុងទាក់ទងរហ័ស៖
  - **📞 Call:** ចុចតេទូរស័ព្ទភ្លាមៗ
  - **✈️ Telegram:** ចុចបើកឆាត Telegram ទៅកាន់លេខ ឬ Username របស់ភ្ញៀវភ្លាមៗ
  - **📝 Note:** ចុចកត់ត្រាការសន្ទនា និងលទ្ធផលតាមដាន

### ៣. ក្តារគ្រប់គ្រងដំណាក់កាល (Kanban Pipeline Board)
- តាមដានភ្ញៀវតាមដំណាក់កាលនីមួយៗ៖
  1. `ព័ត៌មានថ្មី (New)`
  2. `កំពុងតាមដាន (In Follow-up)`
  3. `ណាត់ជួប/ទស្សនកិច្ច (Tour/Visit)`
  4. `ធ្វើតេស្តសមត្ថភាព (Placement Test)`
  5. `ចុះឈ្មោះជោគជ័យ (Enrolled 🎉)`
  6. `មិនទាន់ចាប់អារម្មណ៍ (Lost)`
- អាចអូស (Drag & Drop) កាតប្តូរពីប្រអប់មួយទៅប្រអប់មួយទៀតបានយ៉ាងរលូន

### ៤. ប្រព័ន្ធរំលឹកការងារតាមដានប្រចាំថ្ងៃ (Today's Reminders)
- ប្រព័ន្ធនឹងជូនដំណឹងរំលឹកដោយស្វ័យប្រវត្តិនូវភ្ញៀវណាដែលដល់ថ្ងៃកំណត់ត្រូវទាក់ទងតាមដាន
- មាន Badge ក្រហមរំលឹកនៅលើ Header និង Menu ជួយមិនឱ្យបុគ្គលិកភ្លេច Lead សំខាន់ៗ

### ៥. កត់ត្រាប្រវត្តិតាមដាន (Follow-up History Timeline)
- កត់ត្រារាល់ការហៅទូរស័ព្ទ ឆាត ឬជួបផ្ទាល់ជាមួយភ្ញៀវ
- បង្ហាញជា Timeline ច្បាស់លាស់ពីប្រវត្តិនៃការសន្ទនាកន្លងមកជាមួយបុគ្គលិកទទួលបន្ទុក

### ៦. នាំចេញជា Excel និង Backup ទិន្នន័យ (Export & Backup)
- **នាំចេញជា Excel (CSV):** គាំទ្រ UTF-8 BOM ធានាថាពេលបើកក្នុង Microsoft Excel មិនខូចពុម្ពអក្សរខ្មែរឡើយ
- **Backup & Restore (JSON):** អាចទាញយក File Backup រក្សាទុក និងបញ្ចូល (Restore) មកវិញពេលប្តូរកុំព្យូទ័រ
- **បោះពុម្ពប័ណ្ណព័ត៌មាន (Print Sheet):** មានទម្រង់ Print ប័ណ្ណព័ត៌មានអ្នកសួរផ្លូវការស្អាតត្រឹមត្រូវ

### ៧. ការកំណត់ប្រព័ន្ធ (Customization)
- កែប្រែឈ្មោះសាលា, លេខទូរស័ព្ទ និងអាសយដ្ឋាន
- បន្ថែម/លុប កម្រិតថ្នាក់សិក្សា (Grade Levels)
- បន្ថែម/លុប ប្រភពទីផ្សារ (Marketing Channels)
- បន្ថែម/លុប ឈ្មោះបុគ្គលិកប្រឹក្សា (Counsellors)

## 👥 ប្រព័ន្ធកំណត់សិទ្ធិប្រើប្រាស់ (Role-Based Access Control - RBAC)

ប្រព័ន្ធបានកំណត់សិទ្ធិយ៉ាងហ្មត់ចត់ជា ៤ តួនាទីសំខាន់ៗ ដើម្បីការពារទិន្នន័យ និងសម្រួលការងារតាមផ្នែក៖

| តួនាទី (Role) | គណនីសាកល្បង | ពាក្យសម្ងាត់ | សិទ្ធិ និងដែនកំណត់ (Permissions) |
|---|---|---|---|
| **🛡️ Admin System (អ្នកគ្រប់គ្រងប្រព័ន្ធ)** | `admin` | `123` | **សិទ្ធិពេញលេញ ១០០%:** គ្រប់គ្រងប្រព័ន្ធ, បង្កើត/កែប្រែ/លុប Users, កំណត់សិទ្ធិ, កែ Settings, Backup/Restore, និងលុបទិន្នន័យ |
| **👔 នាយកសាខា (Branch Director)** | `director` | `123` | **សិទ្ធិគ្រប់គ្រងកម្រិតខ្ពស់:** មើល Dashboard & Analytics ទាំងអស់, មើលបញ្ជីអ្នកសួរទាំងអស់, នាំចេញ Excel/CSV, បោះពុម្ព, កែប្រែទិន្នន័យ, តាមដានបុគ្គលិក (មិនអាចលុបទិន្នន័យចោលផ្តេសផ្តាស ឬចូល Settings បានទេ) |
| **💁‍♀️ អ្នកផ្ដល់ព័ត៌មាន (Information / Front Desk)** | `info` | `123` | **សិទ្ធិប្រតិបត្តិការជួរមុខ:** កត់ត្រាអ្នកសួរថ្មី, កត់ត្រាតាមដាន (Follow-up Notes), ផ្លាស់ប្តូរដំណាក់កាល Kanban, Call/Telegram, មើលបញ្ជី និងការងាររំលឹកថ្ងៃនេះ (មិនអាចលុបទិន្នន័យ, មិនអាចចូល Analytics/Settings) |
| **💰 គណនេយ្យ (Accountant / Finance)** | `accountant` | `123` | **សិទ្ធិហិរញ្ញវត្ថុ និងរបាយការណ៍:** មើលផ្ទាំងគ្រប់គ្រងទូទៅ, មើលបញ្ជីអ្នកសួរ និងអ្នកចុះឈ្មោះរៀន (Enrolled), ពិនិត្យថ្លៃសិក្សា & ថ្នាក់រៀន, មើលរបាយការណ៍ និងស្ថិតិ, នាំចេញទិន្នន័យជា Excel (CSV) (មិនអាចបន្ថែម/កែប្រែ ឬលុបទិន្នន័យឡើយ) |

> 💡 **ចំណាំ:** អ្នកអាចចុចលើ Profile នៅជ្រុងខាងស្តាំខាងលើនៃ Header ដើម្បី **ប្តូរតួនាទី (Switch Role)** សាកល្បងបានភ្លាមៗដោយគ្រាន់តែចុច ១ ឃ្លីក (1-Click Switch)!

## 📁 រចនាសម្ព័ន្ធឯកសារ (Project Structure)

```
ប្រព័ន្ធគ្រប់គ្រងទីផ្សារសាលា/
├── index.html          # កម្មវិធីចម្បង (Main Application)
├── Start-App.bat       # ឯកសារសម្រាប់ចុចបើកកម្មវិធីភ្លាមៗ
├── school-logo.png     # ឡូហ្គោសាលារៀន
├── README.md           # សៀវភៅណែនាំប្រើប្រាស់
├── css/
│   └── style.css       # ការរចនា និងពុម្ពអក្សរខ្មែរ (Modern UI & Fonts)
└── js/
    ├── data.js         # ការគ្រប់គ្រងទិន្នន័យ (LocalStorage, Demo data, CSV/JSON)
    ├── charts.js       # ក្រាហ្វិកស្ថិតិ SVG & HTML5 (Offline Charts)
    └── app.js          # ដំណើរការមុខងារទូទៅ (Controller & Events)
```
